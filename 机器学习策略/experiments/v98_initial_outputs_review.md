# V98 首轮输出复盘与修正说明

> 本文下半部分保留首轮输出及修正原因作为实验记录。最终研究结论以 2026-07-15 完整重跑为准。

## 最终重跑结论（2026-07-15）

修正版恢复了 V96/V97 的 `feature_fraction=1.0`，按年份窗口完整获取 P2/P4 大表，压缩十大流通股东明细，并增加 V96 Money2 基准复现门禁。最终输出满足：

- Money2 月度基准 `162/162` 行匹配。
- RankIC最大绝对误差约 `2.78e-17`，Top8 edge最大绝对误差约 `2.44e-8`。
- 所有 point-in-time 违规为0。
- 四张原始大表均无5,000行截断。
- P2/P3/P4 均通过查询与基础覆盖门禁。

最终结果：

| Money2 | 0.0432 | 2.31x | 0.0262 | 2.095% | - |

四个 challenger 均未通过预注册门槛。生产候选继续保持 Money2，不增加 P2/P3/P4，也不使用全量融合。

P2 的最终结果进一步说明 RankIC 与 Top8 不是同一目标。P2 提高了全截面 RankIC，却降低 Precision Lift、MAP和Top8收益。其30/90日解禁比例在2025年接近归零、2026年完全归零，但两个特征仍占 P2 模型约15.6%的 gain，存在明显的源数据年份漂移。当前 P2 bundle 应淘汰；未来若重开，只测试去掉解禁比例后的纯增减持信息。

P3 的财务变化没有带来顶部增量。P4 的数据完整后仍未改善 Top8，说明首轮“未完成”问题已经关闭。真正逐条分析师预期修正 P1 仍为未验证。

完整阶段解释见 `机器学习策略/experiments/weekly_reviews/2026-07-15_csi800_v61_v98_stage_review.md`。

## 阶段性结论

首轮结果只支持两个判断：

1. 在同一套 `feature_fraction=0.8` 对照下，P2 和 P3 都没有改善 Money2 的 Top8 排序，不应加入当前模型。
2. P4 因前十大流通股东表被查询行数上限截断，属于未完成验证，不能判定无效。

当前生产候选继续保持 V97 Money2，不根据首轮 V98 更换模型或做信息融合。

## P2 解释

P2 的 RankIC 提高约 0.0185，但 Precision lift、MAP@8 和 Top8 edge 同时下降。这说明增减持与解禁信息改变了全截面排序，却没有改善本项目真正需要的顶部八只股票。

- P2 新特征平均占模型 gain 的 31.6%，不是模型忽略了它们。
- 30/90 日解禁比例分别有约 99.86% 和 99.58% 的样本为零，却获得较高重要性，存在树模型利用稀疏事件过拟合的迹象。
- 只有 1/3 个种子的 edge 增量为正。
- 2024、2025、2026 均弱于 Money2，2026 平均少约 4.84 个百分点。
- seed42 的同月 Top8 与 Money2 仅重合约 18.5%，说明新增信息对顶部排序扰动很大。

因此 P2 不适合直接作为训练特征加入 Money2。未来若研究它，更适合独立研究低频风险确认或事件后的条件收益，而不是再次投入主模型。

## P3 解释

P3 新特征平均占模型 gain 的 28.0%，主要由净利润同比变化和收入同比变化贡献，但结果没有转化成稳定的顶部收益。

- RankIC 相对 Money2 下降约 0.0148。
- 只有 1/3 个种子的 edge 增量为正。
- 2023、2025、2026 为负，2026 平均少约 2.91 个百分点。
- 财务同比水平与 V46 已有成长、盈利和质量特征部分重叠；低频披露变化被模型赋予较高权重后，增加了更新噪声。
- 公告后超额收益只有约 38% 行有值，重要性较低，没有形成稳定增量。

因此 P3 当前也不加入 Money2。

## P4 查询缺陷

`STK_SHAREHOLDER_FLOATING_TOP10` 缓存恰好为 45,000 行，只覆盖 112 只股票；这对应九个股票批次各自被截在约 5,000 行。最终前十大集中度和机构占比只有约 8.6% 覆盖，P4 被 70% 数据门禁正确拦截。

这保护了模型结果，但意味着 P4 尚未完成。修正版改为按“股票批次 × 公告年份”查询，并将任何达到 5,000 行的单次返回判为疑似截断。

## 首轮实验契约问题

首轮 V98 使用了 `feature_fraction=0.8`，而 V96 验证与 V97 导出 Money2 的冻结协议是 `feature_fraction=1.0`。首轮内部对照仍然同场公平，但不能作为 V97 生产基线的严格增量证明。

修正版已经恢复 `feature_fraction=1.0`，并增加 V96 Money2 逐月精确复现门禁。最终结论以修正版重跑结果为准。
