# V98 Money2 外部新信息准入与增量验证

## 研究问题

V98 只回答一个问题：在 V97 的冻结 Money2 训练协议之外，P1-P4 新信息是否提供可复现的 Top8 排序增量。基线固定为 expanding、label-safe、fixed120、三种子和 `feature_fraction=1.0`。

## 信息语义

- P1 真正分析师预期修正：必须有逐条发布日期、预测目标期、机构或分析师、EPS/净利润预测值。未接入真实明细前不训练，也不使用 jqfactor 静态一致预期代理。
- P2 股东行为与解禁：使用已完成增减持和在历史特征日已经公告的未来解禁。标准数据不保证覆盖预减持与回购。
- P3 实际财务加速度与公告后反应：使用 `get_fundamentals(..., date=feature_date)` 的最新可见财务数据和公告后的相对收益。它不是相对分析师一致预期的 earnings surprise。
- P4 持有人结构：使用股东户数、前十大流通股东集中度和按股东名称/类型可识别的机构占比。

## 实验矩阵

1. `money2`
2. `money2_plus_p2`
3. `money2_plus_p3`
4. `money2_plus_p4`
5. `money2_plus_all_available`

单项变体只有在数据查询成功、存在真实记录、覆盖率达标且时点审计通过后才会生成。组合变体只包含通过数据准入的信息族。

## 验收门槛

- 相对 Money2 月均 Top8 edge 增量不低于 0.20 个百分点。
- RankIC 增量不低于 -0.002。
- 至少 3/5 个 OOS 年份为正。
- 至少 2/3 个随机种子为正。
- 三个月 block bootstrap 正增量概率不低于 65%。
- 相邻截止日分数相关不低于 0.65，Top8 重合不低于 25%。
- 所有发布日期晚于 `feature_date` 的违规数必须为 0。
- 若同目录存在 `v96_core_monthly.csv`，V98 Money2 必须逐月精确复现 V96；不一致时直接终止。

## 解释边界

- P2 的阴性结果不能否定预减持或回购信息，因为标准表未必覆盖这两类前置事件。
- P3 的阳性结果只能说明实际披露及市场反应有效，不能证明分析师预期差有效。
- P4 的机构识别包含名称关键词规则，必须结合覆盖率和特征重要性审计，不能直接视为完整机构持仓。
- P1 若未通过数据准入，输出应为“不可验证”，不是“无效”。

## 运行与交付

先运行 V96 生成 `v96_money2_enriched_panel.csv`，再从头运行 V98。V98 会缓存压缩后的源表和逐月快照；中断后重跑会复用缓存。完成后发送整个 `csi800_ml_v98_external_information_outputs` 目录。

P2/P4 的大表按股票批次和公告年份窗口读取；任何单次查询达到 5,000 行都视为疑似截断并阻止该信息族进入模型。查询只选择实际使用的字段，十大流通股东明细在每个查询块内立即聚合为“股票 × 报告期 × 公告日”一行，随后释放明细和月度快照原始表，避免完整数据修复后出现 OOM。`v3_windowed_compact` 缓存与旧版截断缓存隔离。
